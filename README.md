# 🙇‍♂️ Apology AI (高情商道歉大師)

> 「沒有解開不了的誤會，只有沒找對的語氣。」

Apology AI 是一個專為職場、伴侶、朋友與客戶關係設計的**高情商 AI 道歉產生器**。透過整合大語言模型 (Gemini / OpenAI)，根據輸入的犯錯情境、道歉對象與希望語氣，秒級生成 3 種不同層次的道歉方案與 1 個實用實體補救建議。

---

## 🌟 特點亮點

- **多維度情境設定**：支援 5+ 種常見對象（伴侶、主管、客戶、隊友、長輩）與 3 級嚴重程度。
- **4 種高情商語氣**：真誠感人、專業公關、幽默化解、低姿態道歉。
- **雙 API 模式**：支援免費 Google Gemini API 與 OpenAI API（預設亦提供離線 Demo 擬真保險模式）。
- **一鍵行動**：提供「一鍵複製文案」與「快速分享至 LINE」。
- **純前端極速體驗**：零架站負擔，託管於 GitHub Pages 即可直接使用。

---

## 🚀 快速啟動

1. 將本 Repository 下載或 Clone 至本地。
2. 雙擊 `index.html` 或以 Live Server 開啟即可使用。
3. 可點擊右上角 `🔑 API 設定` 輸入您的 **Google Gemini API Key** 或 **OpenAI API Key**。

---

## 🛡️ 免費 Gemini API Key 取得方式
1. 前往 [Google AI Studio](https://aistudio.google.com/).
2. 以 Google 帳號登入並點擊 **"Create API Key"**。
3. 貼回 Apology AI 網頁右上角即可免費體驗！
